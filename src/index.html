Empreenda Mais Elas

Uma plataforma de apoio a mulheres empreendedoras.

Sobre o projeto

O Empreenda Mais Elas busca reunir informação, incentivo e oportunidades para mulheres que desejam iniciar ou fortalecer seus negócios.

Esta versão inicial é uma página textual criada para demonstrar a estrutura do projeto e o funcionamento da integração contínua.

Próximos passos

Futuras versões poderão incluir conteúdos educativos, divulgação de negócios, rede de apoio e ferramentas para planejamento.
